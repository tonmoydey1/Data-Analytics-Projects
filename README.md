## How to explore

1. Follow a project link above to open its folder.
2. Open `.ipynb` notebooks in Jupyter Notebook, JupyterLab, or VS Code. Check the imports for required Python packages and adjust dataset paths to your local copy before running cells.
3. Open `.sql` scripts in a compatible database client after reviewing their database and table setup. The Swiggy project's SQL queries are provided in `.docx` format.
4. Open `.pbix` dashboards in Power BI Desktop and update data source settings before refreshing. Use the included PDF or image exports to view existing dashboards where available.
5. Read supporting `.docx`, `.pdf`, and `.pptx` files for requirements, reports, and presentations.

For the railway project's setup, methodology, and known issues, see its [detailed README](End%20To%20End%20Data%20Analytics%20Project/Indian%20Railways%20Analysis/README.md).

Project links preserve the existing folder names, including their original spelling and nested directories.
